# Claims and their sources

Every number in `README.md` and in the pages under `docs/` (`system.md`, `evaluation.md`,
`agent.md`, `agent_protocol.md`, `limitations.md`, `roadmap.md`) and in `CHANGELOG.md`, with the
file it comes from. Results files are
regenerated by the commands in `docs/evaluation.md#commands`. Where a number is derived (a
difference, a power, a range), the derivation is given. Parameters of the model itself
(ranges, thresholds, reaction times) come from `config/` or the code, not from results.
